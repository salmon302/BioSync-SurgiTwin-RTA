# ASAM XIL v3.0.0 Port Adapters

Status: placeholder.

This directory will hold Python adapters for the ASAM XIL v3.0.0 API:

* Model Access (MA) Port: variable read and write, step control
* Electrical Error Simulation (EES) Port: hardware fault injection
* Service-Oriented Access (SOC) Port: middleware subscriptions
* ECU Access Port: synchronized memory capture

Scope is defined in SRS FR-VV-002 and FR-VV-003.
